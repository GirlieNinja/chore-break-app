# Chore Break

A shared family chore app for Android: chore reminders, points for every chore you do, and a family shop to spend them in.

## Install

1. On your Android phone, open the **[latest release](https://github.com/GirlieNinja/chore-break-app/releases/latest)** and tap the `.apk` file under **Assets** to download it.
2. Open the downloaded file. If Android asks, allow installing apps from your browser, then tap **Install**.
   (Google Play Protect may warn that the app is unknown — tap **More details → Install anyway**.)
3. Open **Chore Break**, tap **Join with an invite code**, and enter the code you were given.
4. Allow notifications so you get chore reminders and family alerts.

## Updating

Download the newest `.apk` from the [releases page](https://github.com/GirlieNinja/chore-break-app/releases) and install it over the old one. Your points and history are kept.
